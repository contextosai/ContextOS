# Spec working notes (non-normative)

Implementer digests of the ContextOS spec docs, produced while planning this runtime.
They are summaries and can be wrong or incomplete. The published schemas in `/schemas`
and the spec's normative docs win on any conflict; check the source before relying on a
negative ("the spec has no X").

- `foundations.md` — five planes, governance, memory, orchestration, evaluation.
- `implementation.md` — invocation contracts, execution contract, Context Pack, DecisionRecord, MCP.
- `reference-security.md` — profiles, conformance, security controls, components, metrics.
