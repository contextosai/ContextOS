# Agent instructions

- Keep code files at 600 lines or fewer. When a change would push a code file beyond
  that limit, split responsibilities into focused modules or helpers.
- Never commit, push or publish content that exposes the maintainer's machine or
  studies of other projects without the maintainer's explicit approval for that
  specific change. This covers local filesystem paths (`/opt/...`, `/Users/...`,
  `/private/tmp/...`, home directories), and notes, comparisons or lessons drawn from
  other frameworks or repositories cloned locally (file names, commit hashes,
  internal module names or design details read from their source). Keep such
  research outside the repository. Cite public sources (papers, published docs)
  by URL instead, and describe ContextOS's own design in its own terms.
