# ContextOS 0.1.0-alpha.13

The thirteenth alpha of ContextOS. It changes one thing: the Python client is
published on PyPI as **`contextos-client`**.

```sh
pip install --pre contextos-client
```

The module is still `import contextos`. 0.1.0-alpha.12 meant to publish the package
as `contextos`, but PyPI refuses that name as too similar to an existing, unrelated
project, so alpha.12 reached npm only. The Python package now takes the npm package's
name, so both registries use `contextos-client`. The release's wheels are named
`contextos_client-*.whl`.

Nothing else changed. Read the
[0.1.0-alpha.12 notes](https://github.com/contextosai/ContextOS/blob/v0.1.0-alpha.13/docs/releases/v0.1.0-alpha.12.md)
for what changed since alpha.11 and how to upgrade. If you installed an alpha.12 wheel
from its release assets, uninstall it (`pip uninstall contextos`) before installing
`contextos-client`: both provide the `contextos` module.
